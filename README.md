# Laravel Task Manager Frontend

A simple Laravel web frontend for the Task Manager API.

## Running the Frontend

Start the Laravel frontend on port `8001`:

```
php artisan serve --port=8001
```

Open the web page at:

```
http://127.0.0.1:8001
```

## Backend API

The frontend sends requests to the backend API.

**Example**

```
Frontend
http://127.0.0.1:8001

    ↓

Backend API
http://127.0.0.1:8000
```
